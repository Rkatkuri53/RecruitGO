==================================================
OPERATING SYSTEM DEFINITION
===========================

An Operating System (OS) manages computer hardware, software resources, processes, memory, storage, networking, security, and user interaction.

Almost every enterprise application, cloud service, database, and container runs on an operating system.

==================================================
COMMON_MISTAKES
===============

Treating Linux and Unix as identical.

Assuming Windows desktop experience equals Windows Server administration.

Matching candidates on Linux keywords without administration responsibilities.

Ignoring shell scripting for Linux administration roles.

Assuming every DevOps engineer is an expert Linux administrator.

Confusing VMware with an operating system.
