PLATFORM OVERVIEW
=================

IBM WebSphere Application Server (WAS) is IBM's enterprise Java application server used to deploy, host and manage mission-critical enterprise applications.

Modern deployments increasingly use WebSphere Liberty due to its lightweight architecture, cloud-native capabilities and support for containers and Kubernetes.
