PLATFORM OVERVIEW
=================

SAP Integration Suite is SAP's strategic cloud integration platform.

It enables secure integration between SAP and non-SAP systems using APIs, events, messages, and cloud-native integration services.

It replaces many traditional SAP PI/PO integration scenarios for cloud-first architectures.
