API DEFINITION
==============

An API (Application Programming Interface) enables two or more software systems to communicate and exchange data.

APIs are the foundation of modern web applications, mobile applications, cloud-native applications, enterprise integrations, SaaS platforms, and microservices.

AI_DECISION_RULES
=================

Differentiate between

API Consumer

and

API Developer.

Do not assume using an API equals developing an API.

Validate API expertise through

Responsibilities

Projects

Authentication

Security

Integration

Recognize that REST API development is a core requirement for many backend roles.

==================================================
COMMON_MISTAKES
===============

Treating REST as a programming language.

Confusing REST with HTTP.

Treating GraphQL as a database.

Assuming every backend developer has designed APIs.

Ignoring authentication and security responsibilities.

Matching candidates solely because they mention Postman.

Confusing API Gateway with Load Balancer.
