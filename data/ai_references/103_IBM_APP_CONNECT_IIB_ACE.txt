PLATFORM OVERVIEW
=================

IBM App Connect Enterprise (ACE), formerly IBM Integration Bus (IIB) and WebSphere Message Broker (WMB), is IBM's enterprise integration platform for connecting applications, APIs, messaging systems, cloud services and data sources.

It provides message transformation, routing, orchestration and API integration through reusable message flows and event-driven architectures.
