DATABASE DEFINITION
===================

A database stores, manages and retrieves structured or unstructured data.

Different database technologies are designed for different workloads.

Database experience should always be validated using responsibilities rather than product names alone.

==================================================
AI_DECISION_RULES
=================

Validate database expertise using responsibilities.

Differentiate

Developer

vs

Database Administrator

Do not assume a Backend Developer is a DBA.

Do not assume SQL experience equals database administration.

If multiple databases are listed, identify the primary production database.

Recognize common aliases:

Postgres = PostgreSQL

MSSQL = Microsoft SQL Server

HANA = SAP HANA

==================================================
COMMON_MISTAKES
===============

Treating SQL as a database.

Treating MongoDB as a relational database.

Treating Redis as a primary relational database.

Assuming every Oracle user is an Oracle DBA.

Matching candidates only because they listed a database product.

Ignoring responsibilities such as backup, recovery, replication and performance tuning.
