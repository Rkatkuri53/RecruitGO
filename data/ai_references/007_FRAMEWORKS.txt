FRAMEWORK DEFINITION
====================

A framework provides a structured foundation for building software.

A framework depends on one or more programming languages.

Framework knowledge without the underlying programming language should be treated as incomplete unless strong evidence exists.

==================================================
AI_DECISION_RULES
=================

Framework knowledge implies familiarity with its ecosystem but does not replace validation of the underlying programming language.

If a JD requires a framework, verify:

Programming Language

Framework

Responsibilities

Projects

Recent Usage

Do not infer expert-level framework knowledge from a single keyword mention.

==================================================
COMMON_MISTAKES
===============

Treating Spring Boot as a programming language.

Treating React as JavaScript.

Treating Hibernate as a database.

Treating TensorFlow as an AI language.

Matching candidates on framework keywords without validating the underlying language.

Confusing libraries with frameworks.
