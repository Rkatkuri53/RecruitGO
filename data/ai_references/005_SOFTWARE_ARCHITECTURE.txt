SOFTWARE ARCHITECTURE
=====================

Software Architecture defines the high-level structure of a software system.

It determines

System Components

Communication

Scalability

Availability

Security

Performance

Maintainability

Integration

Architecture is independent of programming language.

AI_DECISION_RULES
=================

Do not assume architecture knowledge from programming language alone.

Architecture responsibilities indicate higher seniority.

Candidates demonstrating architecture ownership receive higher scores than candidates who only implemented assigned components.

Differentiate

Implementation

vs

Design

vs

Ownership

Architecture experience should be validated using

Responsibilities

Projects

Deliverables

Technical Decisions

COMMON_MISTAKES
===============

Confusing Microservices with Docker.

Confusing Kubernetes with Microservices.

Treating REST as an architecture.

Treating Cloud as an architecture pattern.

Assuming all Senior Developers are Architects.

Treating SOA and Microservices as identical.

Ignoring architecture responsibilities while matching senior roles.
