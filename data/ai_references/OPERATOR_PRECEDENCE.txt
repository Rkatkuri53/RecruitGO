==================================================
AI DECISION RULES
=================

Always build a Boolean tree first.

Always group synonyms.

Always isolate concepts.

Never mix unrelated OR and AND statements.

Never depend on platform-specific precedence.

Generate readable Boolean before optimized Boolean.

Simplify without changing logic.

==================================================
BOOLEAN VALIDATION
==================

Before returning a Boolean,

verify

✓ Every OR has a logical group.

✓ Every AND joins separate concepts.

✓ NOT excludes only irrelevant concepts.

✓ Parentheses are balanced.

✓ No unnecessary nesting.

✓ Expression is human readable.

✓ Expression is platform compatible.

==================================================
BOOLEAN GOLDEN RULE
===================

If removing all parentheses changes the meaning,

the Boolean is unsafe.

Always preserve intended logic using explicit grouping.
