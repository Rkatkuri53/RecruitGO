PLATFORM OVERVIEW
=================

Oracle Integration Cloud (OIC) is Oracle's cloud-native integration platform for connecting Oracle Cloud applications, on-premises applications, databases, APIs, SaaS platforms and third-party enterprise systems.

It provides application integration, process automation, API management and B2B integration from a unified cloud platform.
