AI_DECISION_RULES
=================

Never compare technologies from unrelated categories.

Always identify technology dependencies.

Understand ecosystem before comparing skills.

Use ecosystem knowledge to discover missing but implied technologies.

==================================================
COMMON_MISTAKES
===============

Confusing frameworks with programming languages.

Confusing cloud platforms with DevOps tools.

Treating databases as programming languages.

Treating Docker as Kubernetes.

Treating React as JavaScript.

Treating SAP as a programming language.

Treating Git as a CI/CD tool.

Treating Kafka as a database.
