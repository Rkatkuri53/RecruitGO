PROGRAMMING LANGUAGE DEFINITION
===============================

A programming language is used to create software, automate tasks, process data, and build applications.

Programming languages belong to different ecosystems.

A language alone does not define a role.

The ecosystem, frameworks, responsibilities and projects determine the actual role.

AI_DECISION_RULES
=================

Never confuse

Java

with

JavaScript.

Framework knowledge without language knowledge is incomplete.

A programming language alone does not determine expertise.

Use frameworks, responsibilities, projects and architecture to validate proficiency.

Prefer candidates with demonstrated production experience over candidates who only list the language.

==================================================
COMMON_MISTAKES
===============

Treating Java and JavaScript as related.

Assuming Python always means AI.

Assuming SQL means Database Administrator.

Treating C# and .NET as separate ecosystems.

Ignoring framework experience.

Matching candidates only because they listed a language.
