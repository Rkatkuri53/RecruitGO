==================================================
AND
===

Purpose

Require ALL connected terms to exist.

Syntax

Java AND Spring

Meaning

Candidate must contain BOTH

Java

AND

Spring

Example

(Java)

AND

(Spring)

Result

Higher Precision

Lower Recall

Use AND for

Mandatory Skills

Core Technologies

Required Experience

Required Certifications

==================================================
OR
==

Purpose

Allow ANY connected term.

Syntax

Java OR Kotlin

Meaning

Candidate may contain

Java

OR

Kotlin

OR

Both

Example

(Java OR Kotlin)

Result

Higher Recall

Lower Precision

Use OR for

Synonyms

Alternative Titles

Equivalent Technologies

Cloud Providers

Framework Variations

==================================================
NOT
===

Purpose

Exclude unwanted candidates.

Syntax

Java NOT JavaScript

Meaning

Find Java

Exclude JavaScript

Example

(Java)

NOT

(JavaScript)

Use carefully.

Too many exclusions remove qualified candidates.

==================================================
PARENTHESES ()
==============

Purpose

Group logical expressions.

Always group OR conditions.

Correct

(Java OR Kotlin)

AND

(Spring OR Micronaut)

Wrong

Java OR Kotlin AND Spring

The second query may be interpreted incorrectly depending on the search engine.

==================================================
QUOTATION MARKS ""
==================

Purpose

Search exact phrases.

Example

"Solution Architect"

Matches

Solution Architect

Does NOT match

Senior Solution Enterprise Architect

Use quotations for

Job Titles

Product Names

Exact Skills

Company Names

Certifications

Examples

"Machine Learning"

"SAP SuccessFactors"

"Enterprise Architect"

"Project Manager"
