==================================================
DATA ENGINEERING DEFINITION
===========================

Data Engineering focuses on collecting, transforming, storing, processing and delivering reliable data for analytics, reporting, machine learning and business applications.

Data Engineers build data platforms rather than reports.

AI_DECISION_RULES
=================

Differentiate between

Data Engineer

Analytics Engineer

Data Scientist

Database Administrator

ETL Developer

Data Architect

Validate using

Pipelines

Transformation

Warehousing

Do not classify reporting developers as Data Engineers unless they build production data pipelines.

Recognize that SQL alone is insufficient to identify a Data Engineer.

==================================================
COMMON_MISTAKES
===============

Treating SQL Developers as Data Engineers.

Treating Data Scientists as Data Engineers.

Confusing Data Warehouse with Data Lake.

Confusing ETL with ELT.

Assuming Hadoop experience automatically means Spark expertise.

Ignoring cloud platform experience.

Matching candidates solely because they know SQL.
