Compute

Security

AI_DECISION_RULES
=================

Do not assume all cloud providers are interchangeable.

Recognize transferable cloud knowledge with reduced confidence.

Examples

AWS → Azure

Medium Transferability

Azure → GCP

Medium Transferability

AWS → OCI

Medium Transferability

Cloud expertise should be validated using

Projects

Responsibilities

Architecture

Automation

Production Operations

Differentiate between

Cloud User

Cloud Administrator

Cloud Engineer

Cloud Architect

==================================================
COMMON_MISTAKES
===============

Treating AWS, Azure and GCP as identical.

Matching candidates only because they list AWS.

Ignoring networking and IAM responsibilities.

Assuming cloud certification equals production experience.

Treating Docker and Kubernetes as cloud platforms.

Ignoring Infrastructure as Code requirements.

Assuming serverless experience equals cloud architecture expertise.
